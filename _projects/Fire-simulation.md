The project's code is under NDA, but I'm allowed to share visuals of the project and tools.

I worked on this project as part of my <strong>internship at Meliora VR</strong>. In this project we were tasked with creating a <strong>realistic fire simulation</strong> that could be used for <strong>training courses</strong> on the <strong>Oculus Quest 2</strong>. I worked on the <strong>VR SDK integration</strong> and creating an <strong>expandable task list</strong> with corresponding tasks like <strong>searching for the fire</strong>, <strong>checking all rooms</strong>, <strong>moving and animating the characters</strong> to the correct position, and <strong>checking the building</strong> to see if there are any <strong>people left behind</strong>. This is all done in communication with an <strong>emergency response professional</strong>.
